# Spider ML Task 1

## Contents:
- Base Task: Create a dense neural network for the FashionMNIST dataset based on the given model architecture and plot training curves, record best weights and make a submission sheet.
- Applied Domain Task: Create a RAG pipeline application that ingests the given PDFs, creates embeddings and retrieves context based on the query, the context is then passed through an LLM with a necessary prompt to give the answer. Along with the required textual answer, it also generates the most relevant image from the PDFs pertaining to the query.
- Bonus Task: Create a denoising autoencoder for the FashionMNIST datset and plot the original and reconstructed images.
